    Databricks and Atlan integration

    Hackathon project, full stack: React, FastAPI, Databricks

    1. ReactTypeScript UI
    2. FastAPIDatabricks App
    3. LangGraphIntent and routing
    4. Genie + AtlanAnswers and lineage
    5. LakebasePostgres state

    The integration lets people ask questions about governed data in plain language. A LangGraph orchestrator works out the intent, picks the right Genie spaces, queries each through its Genie MCP server as the signed-in user, and merges the answers, with charts for query results.

    • Atlan integration. Discovers AI application assets to keep the Genie space registry current, and answers lineage, glossary, data product and AI application questions from the catalog, with upstream and downstream lineage cards.
    • Genie space builder. Lists the tables a user can see, ranks them using Atlan descriptions, owners and certification status, and creates the space as that user after a signed confirmation step.
    • Routing skills. Users save question-to-space routes, private or shared, so repeat questions skip the LLM routing calls.
    • Data engineering. Lakebase Postgres tables for the registry, sessions, chat history and skills. MLflow traces feed a per-user usage and estimated cost view with Excel export.
    • Front end. React and TypeScript, streaming each reasoning step into the chat as it runs, with Recharts for query results.
